# Frontline

An AI front desk for small businesses. A unit of AI agents answers customers on WhatsApp, books and reschedules appointments in Google Calendar, sends reminders, and hands conversations to staff when a human is needed.

Built as a multi-tenant, event-driven system designed for 20,000 businesses: React, Node/TypeScript and Python services, Kafka, Postgres, Redis, Kubernetes.

**Status:** design phase.
